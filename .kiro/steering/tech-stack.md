# Stack tecnológico — Techo Vecino

- **Frontend + Backend:** Astro en modo SSR (una sola aplicación) con endpoints de API.
- **Despliegue:** `@astrojs/cloudflare` → Cloudflare (runtime Workers).
- **Lenguaje:** TypeScript estricto.
- **Base de datos / Auth / Storage:** Supabase (PostgreSQL gestionado).
- **Clientes Supabase:** `@supabase/supabase-js` y `@supabase/ssr`.
- **Validación:** Zod.
- **Herramienta de despliegue:** wrangler.

## Versiones
La última estable al momento del setup, fijadas en `package.json`.
